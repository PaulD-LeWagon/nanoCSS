# DATA MODEL

> **Project:** nanoCSS
> **Date:** 2026-05-07
> **Status:** 🟢 Active


The application is currently **stateless**. It relies on `ThemeConfiguration` (an `ActiveModel::Model`) to manage the state via the frontend, serializing token data to Base64 in the URL or session, rather than persisting it to a database schema.
